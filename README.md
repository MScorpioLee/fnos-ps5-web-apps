# fnOS PS5 Web Apps

为飞牛 fnOS 打包两款可自托管的 PlayStation 网页串流应用。**预览工程，不是索尼官方产品。**

本仓库的目标是应用中心可安装的原生 `.fpk`：桌面入口、应用用户、启动/停止/状态管理、持久化数据与飞牛统一网关。**运行时不依赖 Docker**；构建过程中可以使用容器来隔离编译环境。

## 两款应用

| 目录 | 飞牛应用 ID | 上游 | 工作方式 |
|---|---|---|---|
| `psrp/` | `psrp-web` | [o1298098/remote-play](https://github.com/o1298098/remote-play) | 原生 .NET 服务接入主机，浏览器通过 WebRTC 收发音视频和控制 |
| `chiaki/` | `chiaki-ng-web` | [CSystem77/Chiaki-NG-Web](https://github.com/CSystem77/Chiaki-NG-Web) | Chiaki 库在浏览器 WASM 中运行，原生 Node 服务提供网络桥接 |

上游修订见 [`upstreams.json`](upstreams.json)，各应用构建脚本会记录其实际使用的依赖与修订。两种实现的网络和浏览器要求不同，不能将一种的验证结果当作另一种的通过证明。

## 验证状态

两款预览包已在 fnOS 1.2.1102 / x86_64 上实际安装，应用中心停止/启动、独立用户运行、数据保留与本地网关资源检查通过。**主机配对及真实音视频/手柄仍未验证。** 完整范围见 [验收记录](docs/VERIFICATION.md)。

## 安装与入口

1. 从本仓库 **Releases** 下载目标应用的 `.fpk`（以实际发布资产为准）。
2. 在飞牛应用中心使用本地安装，选择存储空间。首次配对需要自己的 PSN 账户资料及主机上显示的配对码。
3. **通过 HTTPS 登录飞牛管理界面，再打开应用桌面入口。** 不建议把应用嵌在第三方 iframe 内使用。
4. 管理入口为 `/app/psrp-web/` 与 `/app/chiaki-ng-web/`，仅允许已授权的 NAS 管理员访问。应用自身可能还有独立登录，见各目录说明。
5. 外网优先使用已配置好的回家 VPN；不要求将 PS5 设置为 DMZ，也不应照搬公网端口批量开放教程。

两款应用可安装在同一台 NAS，但不要同时争用同一台主机的远程游玩会话。关闭网页不等于一定已经关闭后台会话，切换客户端时应先正常断开。

## 浏览器与验收边界

- 网页能打开、WASM 能加载、WebSocket 能握手，都**不等于**已经配对或串流成功。
- 真正验收必须包括：主机配对、实际视频、实际声音、按键与摇杆输入、松键停止、断线及重新连接。
- 手柄 API、音频启动、全屏与 WASM 共享内存均可能受浏览器安全策略影响。请使用 HTTPS 和可信证书。
- Chiaki-NG-Web 使用 WebCodecs、SharedArrayBuffer 和 AudioWorklet；上游主要列出 Chrome/Edge/Firefox，**本工程不承诺 iPhone Safari 已兼容**。Safari 和 iOS 必须单独实机验收。
- 本项目不会凭网页状态或 API 成功响应宣称低延迟、HDR、震动、自适应扳机或触摸板已通过验证。

## 安全与数据

- 入口优先复用 fnOS 登录校验，后端只绑定本地回环或 Unix Socket，不提供匿名公网控制入口。
- 长期服务使用独立应用用户；不复用、修改飞牛系统数据库。
- 配置、配对密钥与数据库保存在飞牛提供的应用数据目录，不提交 GitHub。
- 卸载默认保留数据；如需清理，先备份并检查具体应用的卸载说明。
- 不改全局 Clash 分流、PT 下载直连、VPN、DMZ、其他应用的防火墙规则或主机加速设置。
- 若经 VPN 能访问 NAS，但 PS5 无声音/画面，可先检查路由器的游戏加速是否干扰该主机的 VPN 路径；需有界对照，不能直接认定是浏览器解码问题。

## 构建与源码审查

每个目录提供自己的获取源码、修补、构建和打包入口；环境要求以该目录 README 为准。构建结束后才生成可安装包，不使用空白 WASM、伪造运行时或下载页替代运行产物。

通用源码检查：

```sh
python3 -m unittest discover -s tools -p 'test_*.py'
python3 tools/check-publish.py .
```

`check-publish.py` 审查当前 Git 索引，避免将常见凭据、数据库和大型构建产物误提交。它不是完整安全审计，不能替代代码审查和实际设备测试。
